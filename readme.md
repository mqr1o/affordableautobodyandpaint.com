# Affordable Auto Body & Paint

Website for an independent auto body and paint shop on Mission Blvd in Hayward, CA.

**Live site:** https://affordableautobodyandpaint.com

![Affordable Auto Body & Paint homepage](screenshot.png)

## Features

- Services, past-work gallery and customer reviews sections
- Live open/closed status based on the shop's hours
- Embedded Google Map for the shop's location
- Tap-to-call phone number and estimate call-to-action
- Responsive layout for phones and desktops

## Tech

A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step), hosted on Netlify with continuous deployment from this repository.
